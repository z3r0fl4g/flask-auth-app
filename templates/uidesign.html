Typography

Primary Typeface

Inter

Modern workhorse for body copy, inputs, and CTAs. Stick to regular/medium for clarity and reserve the heavier weights for Haitian pride statements.

Secondary Typeface

Space Grotesk

Use for hero lines, stats, or countdowns that nod to live event schedules and premium releases.

Scale

  • H1: 3.0rem / 1.2 lh
  • H2: 2.25rem / 1.2 lh
  • H3: 1.5rem / 1.3 lh
  • Body: 1rem / 1.6 lh
  • Small: 0.875rem / 1.5 lh

Usage

Use two heading levels per page, center align only for hero intros, and pair bold Haitian statements with softer supporting copy.

Accessibility

Minimum 16px body size, maintain focus states, and ensure semantic hierarchy for screen readers.

Spacing & Layout

8px Grid System

  • XS: 4px
  • S: 8px
  • M: 16px
  • L: 24px
  • XL: 32px
  • XXL: 48px

Modular spacing keeps dense event info breathable. Stick to multiples of 8 for padding, margin, and grid gaps.

Composition Rules

  • Cards snap to one column on mobile, three on desktop.
  • Max content width ≤ 1120px for readability.
  • Hero sections: 120px top padding, 80px bottom.
  • Keep CTAs above the fold with one secondary action alongside.

Component Library

Buttons

Primary CTAs should appear once per view. Gradients echo our nightlife roots—use sparingly for maximum impact.

Form Inputs

Pair inline validation with approachable helper text so signups and checkout stay calm.

Design Principles

Clarity first

Keep hierarchy sharp, copy concise, and every path obvious. Each screen should answer “What’s my next move?”

Responsive by design

Design mobile-first components that scale gracefully. Break at 640px, 1024px, and 1280px for tuned experiences.

Accessibility always

AA contrast minimum, keyboard navigation, semantic markup, and descriptive alt text remain non-negotiable.

Micro-interactions matter

Use purposeful motion (<300ms) and tactile feedback to highlight state changes, especially around checkout and verification.
